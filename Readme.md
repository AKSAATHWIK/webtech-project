<h1 align="center"> Memory Games</h1>
Memory Cards is an interactive web based memory matching game developed using HTML,CSS and JavaScript.<br>
The game challenges players to find matching pairs of cards across different levels.
## Folder structure

```
webtech-project-main/
│
├── index.html
├── Readme.md
|
├── css/
│   └── style.css
│
├── js/
    ├── main.js
    ├── game.js
    ├── levels.js
    ├── entities.js
    ├── input.js
    ├── ui.js
    └── utils.js
```

### File description
- **index.html** – Main HTML file of the game
- **css/style.css** – Handles styling and layout
- **js/main.js** – Initializes the game
- **js/game.js** – Contains core game logic
- **js/levels.js** – Manages game levels
- **js/entities.js** – Defines game entities
- **js/input.js** – Handles user input
- **js/ui.js** – Manages user interface elements
- **js/utils.js** – Contains helper functions

<h2>Technologies Used</h2><ul>
<li> <b>HTML5</b> - Structures the game and its elements
<li> <b>CSS3</b> - Handles styling,animations and responsive layouts
<li> <b>JavaScript</b> - Implements game logic,card matching,scoring,timers and user interactions.
<li> <b>GitHub</b> - Project hosting.</ul>

## How to run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/AKSAATHWIK/webtech-project.git
```

### 2. Navigate to the Project Folder

```bash
cd webtech-project-main
```
### 3. Launch the Game
- Open `index.html` in your browser.

## How to Play
1. **Select a Level** – Choose a level to begin the game
2. **Flip Cards** – Reveal two cards at a time
3. **Find Matches** – Match identical pairs of cards
4. **Beat the Timer** – Find all matching pairs before time runs out
5. **Progress** – Complete levels and unlock new challenges

## Game Controls

| Key / Action | Function |
|---|---|
| Mouse Click / Touch | Select and flip cards |
| Arrow Keys / WASD | Navigate between cards |
| Enter / Space | Flip selected card |
| P | Pause / Resume |
| R | Restart level |
| Esc | Go back |
| F | Toggle fullscreen |
